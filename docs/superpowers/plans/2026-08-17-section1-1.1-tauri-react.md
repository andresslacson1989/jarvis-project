# Section 1.1 Tauri + React Desktop Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use test-driven-development before implementation and verification-before-completion before any completion claim.

**Goal:** Implement subsection 1.1 as a real Tauri 2 / Rust + React / TypeScript desktop workspace whose production WebView is served from bundled local assets, while preserving the exact authority boundaries and leaving all 1.2+ responsibilities unclaimed.

**Architecture:** `apps/desktop` becomes the real frontend workspace built by Vite; `apps/desktop/src-tauri` becomes a minimal Rust/Tauri application crate. The Tauri production `frontendDist` points only at the generated local `dist` directory. No Core connection, process execution, credential access, provider access, filesystem authority, or consequential custom command surface is introduced in 1.1.

**Pinned stack:** Node 24.18.0; pnpm 11.21.0; TypeScript 6.0.3; Rust 1.97.1; Tauri 2.11.5; tauri-build 2.6.3; @tauri-apps/api 2.11.1; @tauri-apps/cli 2.11.4; React/react-dom 19.2.8; Vite 8.1.5; @vitejs/plugin-react 6.0.3; @types/react 19.2.17; @types/react-dom 19.2.3.
