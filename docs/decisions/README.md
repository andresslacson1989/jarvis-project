# JARVIS Architectural Decision Records

Files in this directory preserve accepted architectural decisions and their rationale.

**Current implementation rules live in the JARVIS v1.0.2 contract suite, not in an overlay of ADRs.**

When an ADR remains valid, its effective rule is incorporated into the active normative documents. If wording in an ADR appears inconsistent with v1.0.2, do not silently choose one: treat it as a contract-maintenance defect and correct the canonical suite.

New material architecture changes require a new unique ADR **and** synchronous updates to every affected active normative file before implementation relies on the decision.

See `docs/JARVIS-CONTRACT-LINEAGE.md` for the canonical lineage and the treatment of the old divergent implementation-lock branch.
