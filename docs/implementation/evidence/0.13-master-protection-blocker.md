Generic repository fetches are not an acceptable substitute for an administration mutation.

2. reread GitHub's live protection/ruleset state;
3. verify every required field in `docs/implementation/governance/MASTER-PROTECTION.md`;
4. record exact live `master` SHA and protection response/settings;
5. only then rescore `0.13` and change it to `VERIFIED`.
