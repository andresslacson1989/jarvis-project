The versions were selected after checking current upstream release information on August 12, 2026. Node 24 is the current LTS family; pnpm 11.21.0 is the current pnpm release; Rust 1.97.1 is the current stable Rust release. ## pnpm / dependency-supply-chain hardening

The root workspace configuration is deliberately fail-closed rather than relying on mutable package-manager defaults:

- exact Node/pnpm versions;
- `engineStrict: true`;
- `pmOnFail: error`;
- `minimumReleaseAge: 1440` (24-hour delay for newly published package versions);
- strict release-age handling, including failure for missing publish times;
- `trustPolicy: no-downgrade`;
- `trustLockfile: false` so trust/age policy is re-evaluated rather than blindly trusting lock metadata;
- exotic transitive dependency sources blocked;
- strict peer dependencies;
- dependency build scripts denied by default (`allowBuilds: {}` + `strictDepBuilds: true`);
- no implicit install before scripts (`verifyDepsBeforeRun: error`);
- exact saves;
- automatic peer installation disabled;
- workspace cycles disallowed.

The initial `pnpm-lock.yaml` contains one exact TypeScript dependency plus its SHA-512 integrity value. No runtime/application dependency was pulled forward merely to populate the lockfile.

## Rust baseline
