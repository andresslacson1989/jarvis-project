## Test runner behavior

`node tools/test/run-tests.mjs --profile normal`:

- discovers tests in deterministic sorted order;
- runs selected files exactly once;
- never implements blind rerun-to-green;
- scrubs arbitrary process environment down to a bounded execution allowlist;
- injects deterministic `TZ=UTC` and `JARVIS_TEST_SEED` values;
- denies common outbound Node network primitives during normal-change tests;
- requires every Phase-0 harness layer to contain executable coverage;
- supports focused `--layer <canonical-layer-id>` execution.

`node tools/test/run-tests.mjs --profile qualification` intentionally fails until all 15 canonical layers contain executable tests. This prevents reserved/empty future layers from being interpreted as release qualification.

## Fixture architecture

`tests/fixtures/manifest.json` and `loadSyntheticJsonFixture()` provide the small deterministic JSON-fixture path. The loader requires:

- unique fixture identity;
- `SYNTHETIC` provenance;
- explicit `containsRealCredentials: false`;
- fixture-root confinement before and after realpath resolution;
- regular non-symlink files;
- 1 MiB maximum size;
- SHA-256 integrity before JSON parsing.

Large binary/media/release fixtures remain owned by later feature layers and must receive their own bounded loader/metadata rather than weakening this small-fixture path.
