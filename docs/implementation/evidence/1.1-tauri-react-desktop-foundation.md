## Tauri context-generation repair

The earlier host used `tauri::tauri_build_context!()` even though `build.rs` used the normal `tauri_build::build()` path without the corresponding generated `tauri-build-context.rs` artifact. Native Windows therefore failed.

The host now uses the standard `tauri::generate_context!()` pairing with `tauri_build::build()`. Regression coverage rejects reintroduction of the invalid pairing.
