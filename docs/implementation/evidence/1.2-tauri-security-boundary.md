## Completed / found

- Added the minimal `main-local-ui` capability with only the bounded opener permission.
- Added production CSP with self-only executable/connectable origins and a separate loopback development CSP.
- Moved native window creation into the Rust composition root.
- Restricted production navigation to the bundled `tauri://localhost` origin.
- Restricted debug navigation to the loopback development server.
- Denied Tauri new-window requests.
- Disabled production devtools in the native window configuration.
- Added a bounded external-link helper accepting only HTTP(S) URLs and delegating opening outside the privileged WebView.
- Preserved the existing inert bundled renderer; no HTML/Markdown execution path was introduced.
- Added positive and negative security-boundary tests.
- Corrected the existing Tauri pairing mutation regression so the test remains valid after the opener dependency was added.
