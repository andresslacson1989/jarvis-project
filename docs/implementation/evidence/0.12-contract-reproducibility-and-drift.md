### Generated artifacts

Tracked deterministic projections:

- `generated/contract/jarvis-v1.0.5.contract-values.generated.json`
- `generated/contract/jarvis-v1.0.5.contract-values.generated.ts`

The generator writes through temporary files followed by rename and supports both write and check modes. Check mode compares exact expected bytes and fails on missing or stale output.

Generated TypeScript is included in the strict TypeScript program and declaration build, so generated source is not an unchecked side channel.

## Atomicity / idempotency / failure properties

- Generation is deterministic for the same canonical bytes.
- Writes use temporary-file + rename semantics per generated file; check mode performs no source mutation.
- Repeated `--write` produces the same tracked bytes and repeated `--check` is side-effect-free.
- Stale or missing generated files fail rather than silently regenerate during CI.
- Contract/profile mismatch fails with stable reason codes rather than rewriting normative documents.
- Manifest mismatches fail rather than automatically changing the canonical matrix or component revisions.
- Generated outputs are projections only and cannot expand contract authority.
