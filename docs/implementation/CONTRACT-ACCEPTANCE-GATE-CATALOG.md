# Contract Acceptance Gate Catalog

This is a non-normative review and evidence catalog for the acceptance sequence. The executable command order remains defined only by tools/ci/localci-gate-manifest.mjs; this catalog does not create a second command manifest. Each row identifies the owning clause, expected output/evidence, authority class, purpose, and why the gate remains distinct. The final Static CI evidence command is terminal evidence capture and is intentionally outside the 30 acceptance gates listed here.
