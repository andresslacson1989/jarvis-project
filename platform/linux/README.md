# Future Linux Platform Boundary — Not V1 Runtime Support

`platform/linux` is a reserved namespace for a future Linux FULL_HOST backend.

For Windows V1 this namespace may contain only contracts, compile-time boundary material, or test fixtures when later work requires them. Subsection 0.2 implements **no Linux runtime backend and makes no Linux support claim**. Directory symmetry is not qualification.

Future Linux production support requires its own explicit platform implementation and qualification under the active contract lineage.
